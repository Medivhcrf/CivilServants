一、勾画：24 句达标，类标偏 5 处

一句一勾这件事过关了（材料一 7／二 4／三 5／四 4／五 3／六 1）。要改的是类标：

位置你标的应该是为什么
材料三 ④⑤⑥⑦（拆真建假／千街一面／门票经济／把居民当布景）做问这四条是"有的地方"出的问题，不是做法；只有最后那句"也有的地方做得细"才是做
材料五 ㉓（委员插话"争的是给游客看还是给人住"）问观这是一句观点／质疑
材料六 ㉔（副市长三条）"总结 意义"结一个句子只许一个类标；这是结论＋做法

一句口诀：能加"某人认为"的是观点，加不上的是事实；事实里"出问题的"标问，"怎么办的"标做。

二、第 1 题（6 / 15）

你的答案（读到的部分）

（划掉）1. 老城更新难首先难在双老，房子老，人也老，老城区 60 岁以上居民占 41%，独居老人近三千人，历史建筑里 60% 是木结构。2. 产权难，一处院子可能分属公房私房。3. 资金难，修缮要按原材料原工艺。
1. 有的地方拆真建假，把真的老宅推了，在别处盖一条仿古街。2. 有的地方千街一面，一条街改造完，有很多卖奶茶，本地手艺、老字号反而租不起。3. 有的地方只顾门票经济，围起一段收 60 元门票，居民要刷身份证回家。4. 有的地方把居民当布景，白天演出，晚上清场。

这一题的分丢得最可惜：你写的前三条正是 B 县的真问题，而且带着数字（41%、近三千人、60% 木结构）——然后把它们划掉了，换成了材料三那四条"有的地方"。题目问的是 B 县，材料三讲的是别处的教训。等于把最值钱的答案亲手划掉。

漏掉的（都勾了，没搬）：

  • 勾画 ④"房租一年涨了两回、老邻居搬走" → 生活成本上升、原住民流失（B 县最核心的一条）
  • 勾画 ⑤"下水道修了两年没通、雨天污水漫门槛" → 重面子轻里子
  • 勾画 ⑥"夜里民宿客人聊到两点" → 居住与经营冲突
  • 勾画 ⑧ 里的"消防通道被占了一半" → 消防隐患

升格版（246 字）

B 县老城更新中的问题主要有五类。一是重"面子"轻"里子"，青石板、老墙修了，下水道却两年未通、一下雨污水漫到门槛。二是生活成本上升、原住民流失，房租一年涨两回，老邻居陆续搬走，院里只剩六户、平均年龄七十岁。三是居住与经营冲突，民宿客人夜里聊到两点，老人在隔壁睡不着。四是"双老"叠加、隐患突出，六成历史建筑是木结构、电线老化，消防通道被杂物占了一半。五是产权复杂、资金缺口大，一处院子分属三类产权、一栋楼谈两年，一年八百万专项资金摊到 136 处不足六万，修旧如旧比重建还贵。此外，一些地方还出现拆真建假、千街一面、门票经济等共性问题。

怎么改的：把你划掉的三条留下并补数字，把材料三那四条压成最后一句"此外……共性问题"。你已经有做对的材料，缺的是判断"哪几条是本题的答案"。

三、第 2 题（9 / 20）

你的答案

双方观点都有道理，一方主张保护优先，老城是不可再生资源，拆一处少一处，算经济账是小账，算文化账才是大账、长远账，商业化一旦过度，老城成了背景留不住人。另一方面应当活化优先，房子没有人住坏得快，财政养不起，过度商业化带来现金流，让修缮转起来，游客来了，店开了，年轻人才愿意回来。总之（划掉"双方各有"）老城既是给人住的，也是给游客看的，两者结合才能良性发展。

只差一句话的距离。 完整句：

两种观点都有道理，但都把"保护"和"人气"对立起来了。

后面完全可以照你写的走，只要每条末尾补一句"它回避了什么"：保护优先回避"房子没人住坏得最快"；活化优先回避"过度商业化会把人和味一起挤走"。你的素材已经够了，缺的是这两句反驳。

四、第 3 题（14 / 45）

你的提纲

标题：老城应当在发展中维护
中心论点：让老城活起来，有人住才有我 让老城活起来
分论点 1：老城是珍贵的旅游资源
分论点 2：老城里的人是持续发展的动力
分论点 3：要良性结合发展

四件都动笔了，这是从 0 到 14 的进步。 问题在"挂不住"：

  • 标题（2 / 5）："应当在发展中维护"是口号，没有动作落点；11 字合规，但从论点里压不出来。
  • 中心论点（4 / 10）：前半句"让老城活起来，有人住才有我"是个好判断（接近"有人住才留得住"），后半句重复了，且被涂改弄乱。写清楚就这一句：老城的价值不在改得多漂亮，而在改完还有没有人住。
  • 三个分论点（8 / 30）：维度乱了——"旅游资源"是经济、"人是动力"是人、"良性结合"是空话。
    • 分论点 1 和你的中心论点打架：把老城当资源，正是"给游客看"那一派。
    • 分论点 3"要良性结合发展"不是分论点，是结论。
    • 修法：选定一组维度，三个都用同一组。人／味／机制这组最稳：①先人后房，把人留住；②业态负面清单＋平价铺面，把味留住；③一栋一策、社区规划师、补人头的机制，把机制留住。

示范提纲（照结构，别照字）

标题：让老城留得住人，也留得住味（13 字）
中心论点：老城更新的成败不在改得多漂亮，而在改完之后还有没有人住。
分论点一：先人后房——把原住民留住，房子才有人气，修缮才有意义。
分论点二：业态负面清单与平价铺面——守住手艺和邻里，味才不会散。
分论点三：一栋一策、社区规划师、补人头不补项目——机制不立，人和味都留不住。
