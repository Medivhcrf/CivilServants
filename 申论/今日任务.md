## 一、材料

**材料一** Y 市 2000 年以前建成的小区有 1200 多个，没有电梯的楼栋 3.2 万栋，小区里 60 岁以上居民占 28%。2021 年起市里推进老旧小区加装电梯，到今年累计装了 800 台，年均不到 200 台。住建局一位科长说："按这个速度，全部装完要一百多年。"

**材料二** 卡住的地方，往往在同一个单元的邻里之间。一楼的住户意见最大：挡住采光、电梯井贴着窗户、运行有噪音，还担心房价被拉低；六楼的盼着早点装，家里老人半年没下过楼。有的单元因为一户不同意就一直搁置——现在的规则要求"本单元全体业主同意"，一户反对就办不成。

**材料三** 钱也是难题。一部电梯连同井道、管线迁移大约 45 万，政府按台补贴 12 万，剩下的 33 万由住户分摊，通常是三楼以上每户 2 万到 4 万。低楼层不愿意出钱，高楼层有的一次拿不出。装好之后每年维保还要 6000 多元，谁牵头收、收不上来怎么办，很多小区装完就卡在这一步。

**材料四** 流程也不轻松。一个项目要跑 8 个部门、盖 11 个章，设计、审图、电力增容、燃气管线迁移各找一家单位，有的小区光跑手续就跑了两年。有居民说："我们不是不想装，是不知道该找谁。"

**材料五** 也有做得成的。H 区搞"成片推进"，一个小区统一设计、统一施工，成本降了 15%；有企业做"电梯代建代管"，装的时候垫资、装完按年收费，居民不用一次性掏；有的社区开"加梯议事会"，把一楼补偿谈在前面——采光补贴、优先停车位、免三年物业费；公积金和住宅专项维修资金也可以提取使用。

**材料六** 一位长期研究老旧小区改造的专家说，加装电梯难的从来不是技术，是利益分配。==重点|关键不在补多少钱，而在把分摊规则、补偿机制、后期维保三件事一次谈清==。他建议：一楼可以不出钱、按次刷卡付费；维保纳入物业统一托管，别让住户自己找人；把加装纳入街道考核，进度慢的要说明原因。

## 二、题目

### 第 1 题（20 分 · 400 字以内）

> **题目**：假如你是 Y 市住建局工作人员，请就"如何推进老旧小区加装电梯"提出对策建议。（400 字以内，20 分）

动笔前先填这张表（**一条对策对一个材料问题**）：

| 材料里的问题 | 谁该管 | 我的对策（40–60 字，抓手：钱／考核／规则） |
| --- | --- | --- |
| 一楼反对、一户否决就搁置 |  |  |
| 分摊出不起、低楼层不愿出 |  |  |
| 维保 6000 元无人牵头 |  |  |
| 8 个部门 11 个章、跑两年 |  |  |
| 不知道该找谁 |  |  |

三条红线：

1. ==做法|第一条必须是判断句==——"推进不下去的根子不在钱，在分摊和补偿没谈清。"
2. ==重点|至少两条带「考核」或「钱」==：考核＝纳入街道／部门考核、进度慢要说明；钱＝补贴、垫资、按次付费、维修资金、公积金。
3. 每条 40–60 字。写不到 40 字说明只有口号，超过 60 字说明在讲道理——对策不需要讲道理。

## T3 · 作文零件（25 分钟）

主题：**"老楼加梯"背后的治理难题**。

1. 立意一句（≤30 字）：必须是**能被反驳的判断**，不许写"要重视""要加强"。
2. 3 个标题（每个 8–14 字，带动作词）：实（动词＋对象＋结果）、虚（借一个具体东西，比如"六楼的那扇窗"）、稳（"既要 A，也要 B"）。
3. 开头段 150 字，四句：现象（一个具体画面）→ 本质（争的是什么）→ 观点（你的立意）→ 引出。
