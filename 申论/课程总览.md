# 课程总览

> 这一页是**课程地图**，不是资料目录。
> 每一课都是「讲义 → 限时练习 → 图解复盘」的闭环：读完讲义不算学过，练习过关才算。

## 怎么用这一套

1. **只读当天那一课的讲义**（20–30 分钟）。一天读三课，等于没读。
2. **立刻做练习，限时，不许翻讲义**。翻着讲义写出来的答案，在考场上一分不值。
3. **交给我批改**，拿到漏点清单后，再去对照图解课件逐句看「哪些是抄的、哪些是自己写的」。
4. **结业标准过了，才进下一课**。没过就回炉同一题型，换材料再练一道。

图解课件不是"看完就懂"的东西——它是**批改之后再看的**，用来把你自己的答案和标准答案逐句比。

## 每课都要过的三道关

不管哪一类题，批改时只查这三件事。**三道关的顺序不能倒**：

| 关 | 查什么 | 不过关的典型症状 |
| --- | --- | --- |
| 一、会找点 | 材料里的采分词有没有被勾出来 | 答案只有中心句，段落后半截全丢 |
| 二、会排队 | 按题目问的**动作**分层次 | 写了题目没问的部分，挤掉正题 |
| 三、会控字 | 字数配比、格式四件、篇幅 | 开头 120 字，主体两句话 |

**找点决定下限，排队决定中段，控字决定上限。** 你现在卡在"一"和"三"：漏后半截（标点切分没做）、篇幅配比失衡。

## 五类题一句话公式

| 题型 | 一句话公式 | 常见字数 |
| --- | --- | --- |
| 归纳概括 | **问什么答什么**：分条 + 每条「中心词 + 具体表现」 | 150–300 |
| 综合分析 | **是什么 → 为什么 → 怎么办**（解释型四段：释义／反面／正面／结论） | 250–350 |
| 提出对策 | **主体 + 动作 + 对象 + 目的**，来源优先级：材料直给 > 问题反推 > 原因反推 | 300–400 |
| 贯彻执行 | **一道归纳概括，穿公文外套**：四问定壳（我是谁／写给谁／为什么／什么场合） | 400–600 |
| 大作文 | **一个中心论点 + 三个分论点**，每个分论点「是什么—为什么—怎么办」 | 1000–1200 |

完整展开见 [五大题型公式](types.html)。

## 讲义为什么只有这几课

目前写全讲义的只有**第 3 课、第 4 课**，加上方法层的[找点方法论](points.html)、[五大题型公式](types.html)、[表达与素材库](vocab.html)、[批改评分标准](rubric.html)、[示范课九步法](nine-steps.html)。

第 1、2 课当时是边讲边练，方法散在练习诊断里，没有单独成文；第 5、6、7 课还没讲到。**补讲义按上课顺序来**，不提前写——写了也用不上。

## 一个提醒

讲义里的所有例句、范文、材料，都是**可以拆的东西**，不是背的东西。背范文在申论里几乎不得分——阅卷看的是你有没有从材料里把点找齐。真正要背的只有两样：**格式四件**和**字数配比**。
