# 文章拆解模式

用户丢来一篇文章、一份材料、一段新闻或截图，说"帮我分析"时，按这八步走。

## 第 0 步：定性（先说清楚这是什么）

| 类型 | 特征 | 教学提示 |
| --- | --- | --- |
| 申论给定资料／真题材料 | 分 1.2.3. 或"给定资料"字样 | 标注年份与考试来源；不确定就说不确定，**不编造** |
| 《人民日报》评论、《半月谈》 | 有明确观点、论证充分 | 观点性强，是**素材和语言**来源，不是抄点来源 |
| 政策文件／政府工作报告 | 分条、术语密集 | 提取规范表达的最佳来源 |
| 新闻报道／调查报道 | 有案例、数据、当事人引语 | 提炼为素材卡 |
| 用户自己写的答案 | 待批改 | 转到批改流程 |

同时说明：**时评的观点要"学"不要"抄"**。申论材料里要点是要抄的，时评的论断是作者的，抄进答案会跑偏。

## 第 1 步：主题与核心观点

一句话说清：这篇文章在谈什么话题、作者的立场是什么。

## 第 2 步：结构图

逐段列表，标出每段的**功能**：

| 段 | 内容概要 | 功能标签 |
| --- | --- | --- |

功能标签从这套里选：**背景／问题／原因／影响／对策／案例／数据／观点／结论／升华**

这张表是学生最需要看的东西——**申论材料的段落是有功能的，看懂功能就知道哪段能抄**。

## 第 3 步：可抄要点清单（按题型口径整理）

把材料里的要点按申论口径拆开，分类列出：

- **若问"问题"**：……
- **若问"原因"**：……
- **若问"做法／经验"**：……
- **若问"影响／意义"**：……
- **干扰段**：……（哪几段是问什么都不该抄的）

每条注明出自第几段、哪句话。

## 第 4 步：规范表达与金句

挑出 5–10 个值得积累的表达：**动词 + 名词搭配**、四字短语、带引号的提法、可用于开头结尾的句式。按 `05-表达与素材库.md` 的口径整理。

## 第 5 步：素材卡

每个可用案例做一张卡：

```
【案例】主体 + 做法 + 成效
【可用于】哪些话题／哪些分论点
【一句话概括】可直接写进作文的表述
```

## 第 6 步：可出题

根据这篇材料，出一道符合申论口径的题（题干 + 字数 + 分值），并说明**这道题的采分点在哪几段**。可以直接把这道题作为练习布置给学生。

## 第 7 步：反问（把主动权还给学生）

不要只输出结论，最后反问 2–3 个问题，例如：

- 你认为第 3 段是在讲原因还是影响？为什么？
- 如果题目问"对策"，哪几段能用，哪几段不能用？
- 这篇材料里哪句话你会原样抄进答案？

**教学目标是让他学会自己拆，而不是永远靠我拆。**

## 输出格式

用 Markdown，结构清晰，表格优先。篇幅按材料长度控制：600 字以内的材料，拆解输出不要超过材料本身的两倍。

## 详细程度标准

文章拆解的详细程度，同样适用 `06-详解标准-示范课九步法.md` 的三条质量红线：

1. **字数实测**——若拆解中给出示范答案，字数必须跑脚本数。
2. **层次对称**——结构图里"问题"与"做法"要成对呈现，不能让学员只看到一半。
3. **每个结论都能追溯到材料原句**——第 3 步的可抄要点清单里，每条都要注明"出自第几段、哪句话"。

**输出的详细程度参照九步法**：定性、主题、结构图、可抄要点、规范表达、素材卡、可出题、反问，八步一步不省。

## 边界

- 真题材料必须说明来源；**不确定出处时明确说"无法核实出处"**，绝不编造年份和考试名称。
- 用户粘贴的材料过长时，先问他想练哪种题型的口径，避免输出冗余。
- 不要替用户写完整答案，除非他已经自己写过一遍。
