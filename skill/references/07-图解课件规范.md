参考成品：`/home/crf/single_cat/申论/第2课-综合分析-图解.html`

## 交付位置与命名

```
/home/crf/single_cat/申论/<课次>-<主题>-图解.html
```

例：`第2课-综合分析-图解.html`。单文件自包含（CSS / JS 全部内联），不依赖任何外部资源。

## 固定六色语义（不可随意改）

| 颜色 | CSS 变量 | 含义 |
| --- | --- | --- |
| 灰 `#64748b` | `--c-bg` | 背景 / 引子 |
| 蓝 `#2563eb` | `--c-meaning` | 意义 / 价值 |
| 红 `#dc2626` | `--c-problem` | 问题 / 危害 |
| 绿 `#059669` | `--c-action` | 做法 / 对策 |
| 紫 `#7c3aed` | `--c-conclusion` | 观点 / 结论 |
| 琥珀 `#d97706` | `--c-define` | 释义 |

**颜色是语义，不是装饰。** 全套课件必须保持一致，目的是让学员读材料时形成条件反射（看到红＝问题，看到绿＝做法）。

## 七个必备板块

1. **审题** —— 四要素卡片
2. **段落功能地图** —— 每段功能标签 + 要不要用
3. **材料 × 答案　对照工作台** —— 双栏联动（核心）
4. **标点切分法实战** —— 逐句表，标出必写／可省
5. **重新排队** —— 骨架流程图
6. **反面教材** —— 错误版本 + 打叉的错因
7. **可迁移骨架** —— 公式填空

## 三个必备交互

### ① 段落功能色标
每个 `.para` 左边框按功能上色，配一行功能标签胶囊 + "第 N 段"编号。

### ② 答案句 ↔ 材料句 悬停联动（核心机制）
- 答案块写 `data-src="m3-3,m3-4"`
- 材料句子写 `id="m3-3"`
- 悬停答案块 → 给对应材料句加 `.hl`（黄底 `#fff3c4`）
- 点击 → 钉住高亮（`.on`），方便对照抄笔记

### ③ 注释展开
答案块内嵌 `.ans-note`，默认 `display:none`，悬停或钉住时显示。注释内容必须写出"这句答案对应材料哪一句、用了什么手法、哪里是合并、哪里是加工"。

---

## 硬性一致性要求

1. **「完整答案（考场版）」面板必须与「逐句注释」版逐字一致。**
   两者是同一份答案的两种呈现。不一致会让学员不知道哪个是正式答案。
   > 踩过的坑：压缩字数后只改了一个版本，导致 250 字 vs 255 字、缺了正面层总起句，两版对不上。**必须跑脚本比对。**
2. **不抄的句子要显式标注。** 数据句、过渡句不是采分点，用 `.pnote` 标出"可省略／不抄"及原因。
3. **顶部图例吸附**（`position:sticky`），滚动时始终可见。
4. **响应式**：窄屏（≤920px）下双栏变单栏。

## 交付前必须跑校验

```bash
python3 /home/crf/.dsh/skills/shenlun-tutor/scripts/check_diagram.py <file.html>
```

检查五项：`data-src` 引用的 id 是否都存在 / 标签是否闭合平衡 / 答案块数是否等于注释块数 / 考场版与逐句版是否逐字一致 / 字数是否实测并在上限内。

**校验不通过不得交付。**

## 交付前必须渲染验证

用 headless Chrome 截图，肉眼确认排版：

```bash
google-chrome --headless --disable-gpu --no-sandbox --hide-scrollbars \
  --window-size=1280,1500 --screenshot=/tmp/shot/x.png \
  --virtual-time-budget=2500 "file:///path/to/file.html"
```

**注意：锚点（`#id`）在无头截图模式下不滚动。** 要截取页面中段，生成一个临时副本，在 `</head>` 前插入 `<style>#s1,#s2{display:none}</style>` 把前面的板块隐藏掉，让目标板块顶到最上面。

要验证**悬停态**，生成临时副本并强制状态：

- 把目标答案块改成 `class="ans on"`
- 把对应材料句改成 `class="s hl"`
- 插入 `<style>.ans.on .ans-note{display:block}</style>`

截图后必须用读图工具实际查看，确认无排版错乱、无文字溢出。
