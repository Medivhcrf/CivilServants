### 反复出现的失分模式（按严重程度排序）

1. **概括层级过高、字数严重不足**（练习 1：40 字／200 字）。
   → 修法：每条必须展开到 35–45 字；写完先数字数，不足就是漏点。
2. **只抓中心句、漏掉段落后半截**（练习 3：漏"培训偏理论""农房抵押贷款受限""无集体经营主体"）。
   → 修法：**标点切分法**，按句号分号切句，一句一勾。
3. **用生活经验替换材料原词**（练习 2：把"先服务、后收费"读成"先改造再议价"）。
   → 修法：做法题必须原样搬运材料词汇；带引号的词 100% 是采分词。
4. **动宾结构不完整**（练习 2：只写方式，丢了核心动作"引入专业物业企业"）。
   → 修法：每条答案自检"动词 + 宾语"是否齐全。
5. **答非所问：写了题目没问的部分**（练习 6：119 字、占 39.7% 的篇幅用来概括题目没问的"问题"，直接挤掉两条对策）。
   → 修法：动笔前先数题目问了几个动作，问几个就写几块。**练习 7 已改正（结构完全正确）。**
6. **篇幅配比失衡**（练习 7：两个动作，表现 190 字／建议 195 字几乎一比一；而表现约 10 分、建议约 15 分，黄金比应为 1/3 : 2/3）。多写的 60 字正好等于漏掉的两条建议。
   → 修法：按分值分配篇幅，写完两段各自数字数。**新出现，待巩固。**
7. **「概括」吃掉采分词**（练习 7：把材料「对全市政务App和**工作群**全面摸排」概括成「全面梳理排查各类政务平台」，「工作群」三个字蒸发，连锁丢掉"精简合并工作群"这 2 分；把「**保留**一个统一的『掌上政务』平台」写成「**搭建**统一规范的政务平台」，方向还反了）。
   → 修法：**概括是给"问题"用的，不是给"对策"用的；对策要精确，不要简洁。** 材料里的「动作词＋对象词」原样抄进自己的句子。**新出现，待巩固。**

### 已建立的好习惯（继续保持）

- 审题正确，问什么答什么，不抄干扰段（练习 2、3 均未误抄做法段／观点段）。
- 已能写出"中心句 + 具体现象"的标准结构（练习 3 第 2、4 条）。
- 归类判断基本可靠（把"产权不清导致资本撤资"归入资金问题）。
- **能把数据句转化成概括词**：练习 5 把"120 个／30 万平方米"提炼为"增量指标"，而不是当废字跳过。
- **开始脱离模板**：练习 5 未硬套"这句话指出……"，第 1 段直接给释义，读起来更自然。

- **巩固**：字数写满——练习 5 只写了 207/250，偏薄。
- **待作答**：**练习 8**（贯彻执行 · 「厉行节约 反对浪费」倡议书，450 字 / 25 分）。题目、完整材料、采分点预判存于 `10-第4课-贯彻执行.md`；**示范课件已给**：`申论/第4课-贯彻执行-图解.html`（含 410 字范文、九件格式解剖、逐句溯源、字数配比）。批改时对照该课件里的 10 个内容采分点 ＋ 5 分格式分。

  - ②**对策／倡议里的材料原词不许概括**（概括只给"问题"用）。
- **第 3 课已结业**：对策三个来源（材料直接给 > 问题反推 > 原因反推，**不许倒过来**）、公式「主体＋动作＋对象＋目的」、七维度清单、三道防线（针对性／可行性／具体性）——均存于 `09-第3课-提出对策.md`。

## 换一台机器如何继续

**已经同步在 GitHub 上的（任何机器都能拿到）：**
- 全部材料与方法论 → `skill/`（skill 的完整镜像，含 `references/00~10` 与 `scripts/check_diagram.py`）
- 全部图解课件与学生用书 → `申论/`
- 站点构建与发布工具 → `tools/`
- **进度、分数、逐题诊断** → `skill/references/00-学习路线与进度.md` 与 `申论/练习记录.md`

**没有同步、需要在新机器上做一次的：**
- `~/.dsh/skills/shenlun-tutor/` 是**本机安装位置**，不会跟着仓库走。新机器上要从仓库的 `skill/` 复制回去。
- 对话历史不会跟着走。但**接续所需的状态都在上面那两个文件里**，新会话读一遍即可接着教。

**新机器上的一次性动作：**

```bash
git clone git@github.com:Medivhcrf/CivilServants.git
cd CivilServants
mkdir -p ~/.dsh/skills
rm -rf ~/.dsh/skills/shenlun-tutor
cp -r skill ~/.dsh/skills/shenlun-tutor
```

然后对新会话说一句：**「读 ~/.dsh/skills/shenlun-tutor/references/00-学习路线与进度.md，我们继续上第 4 课，练习 8 等批改。」**

**本机改完 skill 后要做的同步（否则仓库副本会过期）：**

```bash
cd /home/crf/single_cat && rm -rf skill && cp -r ~/.dsh/skills/shenlun-tutor skill
./tools/publish.sh "更新 skill 与进度"
```

> 只读学习的话，**其实不需要装 skill** —— 直接打开站点即可，材料、图解答案、进度表全在上面。
> skill 的作用只是让 AI 助教保持同一套教学标准（详解九步法、批改五块模板、图解规范）。
