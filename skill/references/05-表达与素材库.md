# 表达与素材库

申论的语言是**政府话语体系**：准确、平实、有力度，不抒情、不口语、不网络化。

## 一、分类词汇表（按功能背，不要按字母背）

### 问题类
滞后、缺失、缺位、错位、薄弱、粗放、不规范、不均衡、不充分、不协调、短视、悬空、断层、梗阻、瓶颈、短板、盲区、顽疾、痼疾、老大难

### 原因类
思想认识不到位、体制机制不健全、责任落实不力、投入保障不足、专业人才匮乏、监督管理缺位、标准规范缺失、协同联动不够、激励约束不强、基层负担过重

| 动词 | 常见搭配 |

| 强化 | 组织领导、责任落实、底线思维 |
| 健全 | 制度体系、工作机制、考核标准 |

| 优化 | 资源配置、服务流程、营商环境 |

| 压实 | 主体责任、属地责任 |
| 细化 | 任务分工、工作台账、时间节点 |
| 兜底 | 基本民生、困难群体 |

### 成效类
明显改善、持续提升、有效缓解、逐步健全、不断增强、稳步推进、成效初显、实现突破、走深走实、落地见效

## 二、句式模板

**总括句**
- 当前 XX 主要存在以下问题：
- XX 的做法主要有：
- XX 面临的困难集中在以下几个方面：

**分条**
- 一是……二是……三是……
- 1.……2.……3.……

**对策句式（套"主体+手段+内容+目的"）**
- 由 XX 牵头，通过 XX 方式，做好 XX 工作，实现 XX。
- 建立健全 XX 机制，明确 XX 责任，推动 XX 落地。

**结论／收口**
- 唯有……才能……
- XX 是……的关键／基础／保障／前提。
- 让 XX 成为……的……，需要……。

## 三、大作文框架

**标题**
- 对仗式：`以XX之笔 绘XX之景`
- 动宾式：`让XX在XX中焕发生机`
- 主副标题：`XX：XX的必由之路`

**开头（三句法）**
> 背景（时代／政策／现象）→ 提出问题或矛盾 → 亮明中心论点

**分论点（五段三分的核心）**
- 句式统一：`XX是YY的ZZ`（如"完善制度是基层减负的根本保障"）
- 三个分论点之间必须**并列或递进，不能交叉重复**
- 段落公式：**分论点 + 阐释 + 例证 + 回扣**

**结尾**
> 回扣主题 → 适当升华（不含糊拔高）→ 一句有力量的收束

## 四、素材卡模板

每读一篇文章，做一张卡：

```
【主题】
【核心观点】（一句话）
【可用案例】主体 + 做法 + 成效
【可用于】哪些话题／哪类分论点
【可抄表述】直接能写进答案的短语或句式（3–5 条）
【出处】文章名／报刊／日期
```

素材卡存在 `/home/crf/single_cat/申论/素材/` 下，一篇文章一个文件。

## 五、每日 15 分钟积累法

1. 读一篇《人民日报》评论或《半月谈》文章（不求多，求透）
2. 圈出 3 个动词搭配（如"压实责任""打通堵点"）
3. 抄 1 句可用于开头或结尾的句式
4. 记 1 个案例（主体+做法+成效）
5. 写进素材卡

**注意**：积累的目的是**改变自己下笔用词**，不是攒一堆背不完的句子。每积累一个新词，下一次作答就要**强制用上一次**。
