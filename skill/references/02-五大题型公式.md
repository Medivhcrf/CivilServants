# 五大题型公式

## 一、归纳概括题

- **问法**：概括、概述、归纳、整理、简述
- **骨架**：总括句 + 分条（核心词前置）
- **答案来源**：全材料中与题干对象相关的段落
- **纪律**：问什么答什么；一句一勾；每条 35–45 字；用材料原词
- **常见失分**：字数不足（漏点）、概括层级过高、只抄中心句漏后半段、抄了干扰段

## 二、综合分析题

**一句话区分**：概括题是"找点、平铺"，综合分析题是"找点、串成一条链"。

所有综合分析题共享一条骨架：

> **是什么 → 为什么 → 怎么办**

| 类型 | 典型问法 | 骨架 |
| --- | --- | --- |
| 解释型 | 谈谈你对"XX 这句话"的理解 | 释义 → 分析原因／影响 → 结论 |
| 评价型 | 对"XX 现象"进行评析／谈谈看法 | **表态** → 论证好坏 → 结论 |
| 比较型 | 比较 A 与 B 两种做法／观点 | 分别概述 → 比较异同 → 得出结论 |
| 启示型 | "XX"给我们哪些启示 | 经验教训 → **提炼成普适原则** → 怎么做 |

### 解释型三步落笔

1. **释义**：把题目那句话翻译成大白话，**必须落到材料的具体话题上**。
   ✗ "不能只算眼前账" → "不能短视"（太虚，不得分）
   ✓ 说清楚在什么事上短视、眼前账指什么、长远账指什么
2. **分析（得分主力，两层）**：
   - 为什么不能只算眼前账 → 材料里的问题、危害、原因
   - 算长远账要怎么办 → 材料里的做法、经验、对策
3. **结论**：一句收口。不写"综上所述""我认为"，直接写结论本身。

### 常见失分

只释义不分析（只答"是什么"）／评价型不表态／散点罗列没有逻辑层次／脱离材料自己发挥见识／把原因和影响混在一起。

### 特别提示

解释型、评价型答案容易写成"四个散点"，务必检查是否呈现了**递进的逻辑层次**。启示型不抄具体做法，要做抽象提升（去掉具体地名，提炼为可推广的原则）。

## 三、提出对策题

- **问法**：提出建议、措施、意见、解决方案
- **四种来源**：
  1. 材料里的直接对策（最优先，抄）
  2. 问题反推对策（有问题就有对应措施）
  3. 原因反推对策（治病根）
  4. 经验借鉴（他人做法本地化）
- **对策公式**：

> **主体 + 手段 + 内容 + 目的**
> （谁 · 通过什么方式 · 做什么 · 达到什么效果）

- **七个常用维度**：思想（宣传教育）、制度（法规政策）、技术（平台数据）、资金（投入多元）、人才（培养引进）、监督（考核问责）、机制（协同长效）
- **常见失分**：对策空泛不可操作（"加强重视""提高认识"）／没有针对性／只抄问题不写对策／缺主体

## 四、贯彻执行题（公文／应用文）

- **问法**：写一份讲话稿／倡议书／公开信／工作方案／汇报材料／简报／短评／编者按／导言／讲解稿／建议书
- **四要素先想清楚**：**身份**（你是谁）· **对象**（给谁看）· **目的**（为什么写）· **场景**（什么场合）
- **骨架**：格式（标题／称谓／正文／落款）＋ 内容（发文目的 → 主体内容 → 号召或要求）
- **常见失分**：格式错／语气身份不符（对领导用命令口吻，对群众用公文腔）／正文要点不全／写成了大作文

## 五、大作文（申发论述）

- **分值** 35–40，**字数** 1000–1200
- **立意**：题干关键词 + 材料主题 → 中心论点。立意跑偏，全篇报废。
- **结构**：五段三分（开头 → 3 个分论点段 → 结尾）或六段
- **分论点来源**：材料里的对策／意义／原因，升格成论点句
- **论证公式**：**分论点 + 阐释 + 例证 + 回扣**
- **语言**：政府话语体系，不用网络语、口语、抒情腔
- **常见失分**：立意跑偏／分论点重复或交叉／例子空洞或过度堆砌／字数不足／没有回扣主题

## 通用自检清单（交卷前逐条过）

1. 审题：问的是什么？答的是不是这个？字数上限是多少？
2. 覆盖：每一段都处理了吗？有没有漏掉后半段？
3. 结构：分条了吗？核心词前置了吗？总括句有吗？
4. 用词：关键词是材料原词吗？带引号的抄了吗？
5. 字数：写到上限的 90% 以上了吗？
