## 一、摸底先看三件事（比分数重要）

1. ==问题|材料页一个字没勾==。六段材料的右栏全空，第一页边上写着"我还是做不了这个"。于是四道题都是**凭印象写**——所以第 1 题才写成"房租上涨明显"，而材料里有"一年涨了两回""老邻居陆续搬走""剩六户、平均年龄七十岁"三处证据，一个没搬。
2. ==问题|三道题是同一个动作：把材料复述一遍==。第 2 题整段"一方主张……另一方主张……"，第 3 题整段搬 A 市做法。题目问的是**你**，不是材料说了什么。
3. ==问题|字数全线不足==：110 / 250、200 / 300、180 / 400。考场上这样写，每题自动丢掉三分之一的分。

还有一行你没交："每题用时与卡点"——那是摸底最值钱的数据。

**升格版（240 字）**

> B 县老城更新中的问题主要有五类。一是重"面子"轻"里子"，青石板、老墙修了，下水道却两年未通、雨天污水漫进门槛。二是生活成本上升、原住民流失，房租一年涨两回，老邻居陆续搬走，院里只剩六户、平均年龄七十岁。三是居住与经营冲突，民宿客人夜里聊到两点，老人在隔壁睡不着。四是"双老"叠加、隐患突出，六成历史建筑是木结构、电线老化，消防通道被杂物占了一半。五是产权复杂、资金缺口大，一处院子分属三类产权、一栋楼谈两年，一年八百万专项资金摊到 136 处不足六万，修旧如旧比拆了重建还贵。

## 三、第 2 题（7 / 20）

**你的答案（要点）**

> 1、一方主张保护优先……不能只算眼前的经济账，要算文化账长远账…… 2、不是只算经济账，而是要有入住，有人住房子才不会坏得快。我们要理解财政的压力……空城才是对老城最大的伤害。 城市，既是给人住的，也是给游客看的，两者结合才是对老城最好的保护。

| 采分点 | 判定 |
| --- | --- |
| 表态／判断句 | ✗ 0 / 4：**第一句还是复述**（第四次了） |
| 观点一：合理处＋边界 | △ 1.5 / 4：理由复述得对，没指出它回避了什么 |
| 观点二：合理处＋边界 | △ 1.5 / 4：同上，没写"过度商业化会把人挤走" |
| 结论有落点 | ✅ 2 / 4：最后一句是判断，但太笼统，没挂到"给谁用" |
| 语言／字数 | △ 1 / 4："我们要…我们要…"；200 / 300 |

**升格版（290 字）**

> 两种观点各有道理，但都把"保护"和"人气"对立起来了。保护优先看到了老城不可再生，强调文化账、长远账，这一层没错；但它回避了一个现实：房子没人住坏得最快，136 处老宅靠八百万财政养不起，冻结式保护最后保护的是空房。活化优先看到了这个现实，主张用商业现金流养修缮，也没错；但它没回答"活化到什么程度"——过度商业化之后，本地手艺人和老住户被租金挤走，老城就成了布景，游客拍完照就走。所以真正的分歧不是保不保、商不商，而是这地方**给谁用**。A 市的答案是"先人后房"：先摸清谁愿意留下、留下有什么困难，再谈修和改，用业态负面清单和平价铺面守住"味"。能留住人的活化才是保护，留不住的繁荣是假的。

**带走一句**：评析题的第一句，必须是自己的判断——"两种观点各有道理，但都把 A 和 B 对立起来了"。

## 四、第 3 题（9 / 20）

**你的答案（要点）**

> 1、摸清基本情况，摸清愿意留下的，留下的有什么困难，要积极解决 2、修旧如旧，材料从旧料市场收 3、商业项目筛选，烧烤、酒吧、重油烟、高分贝娱乐不能进 4、留出一定铺面打折给本地手艺人和老字号 5、改造期间不强制搬走人，一段一段施工

**问题**：五条**全是材料四 A 市的做法**。题目问的是"你（专班工作人员）就 B 县的问题提建议"，而 B 县的问题恰好是 A 市没犯的：下水道没修、房租涨、消防隐患、原住民走了。==做法|对策要一条对一条回答第 1 题的问题==，再加执行主体与保障。

**升格版（380 字）**

> 一、先摸底、再动工。逐户建立"留居意愿台账"，登记愿不愿留、留下有什么困难；行动不便的改坡道、装扶手，独居的接入社区助餐，把"留人"落到具体事上。二、里子优先、修旧如旧。把下水道、电线、消防通道单列工程先行改造，不能只修门脸；修缮按原材料原工艺做，缺料从旧料市场收。三、建立业态负面清单。烧烤、酒吧、重油烟、高分贝娱乐一律不进；留出不低于三成的铺面，以市场价六折定向租给本地手艺人和老字号。四、改"补项目"为"补人头＋补服务"。专项资金向留下原住民、做适老化改造的主体倾斜；公房做"平价铺面"平抑租金。五、机制兜底。设社区规划师常驻老城，居民意见直接找他；"一栋一策"建档，修哪里、怎么修、谁出钱写清楚；改造分段施工、留居民通道，不强迁。

## 五、第 4 题（0 / 45）——今天教一套 5 分钟提纲

你写"给我提供一下吧，我不会写"。不会写很正常，因为**没人给过你骨架**。骨架只有四件东西：

| 件 | 怎么写 | 今天的示范 |
| --- | --- | --- |
| 中心论点 | 一句可判断的主张（"不是 A，而是 B"／"既要 A，也要 B，但落到 C"） | 老城更新的成败不在改得多漂亮，而在改完之后还有没有人住 |
| 分论点 1 | 第一个维度 | **留人**：先人后房，人留住，房子才有人气 |
| 分论点 2 | 第二个维度 | **留味**：业态负面清单＋平价铺面，守住手艺和邻里 |
| 分论点 3 | 第三个维度（往机制收） | **留机制**：一栋一策、社区规划师、补人头不补项目 |
| 标题 | 从中心论点压到 8–14 字，带动作词 | 让老城留得住人，也留得住味（13 字） |

三个分论点的维度任选一组：**是什么／为什么／怎么办**、**政府／市场／居民**、**人／味／机制**。选一组，填三句，5 分钟就出来。
